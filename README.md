# MazeVerse 🧩

An algorithm-powered maze adventure game built for our DSA course project.

## Features
- Three modes: Flood Escape, Monster Chase, Two-Player Maze Race
- Difficulty levels: Easy (4x4), Medium (6x6), Hard (8x8)
- Procedurally generated mazes with solvability check
- Step-by-step solver visualization (Recursive Backtracking and BFS)
